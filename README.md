# CAMEL Accelerator IP

## IP Structure
This IP is composed of RISC-V CPU (Rocket), DNN accelerator (Gemmini). You have to connect DRAM controller and peripherals to run this IP.

## How-to
1. Create your vivado project
2. Open IP Catalog<br/><img src="figs/1.png" alt="drawing" width="800"/>

3. Add this Repository, then you can see CAMEL's hardware accelerator IP is added to your project.\
<img src="figs/2.png" alt="drawing" width="800"/><br/><img src="figs/3.png" alt="drawing" width="800"/>

4. Open your block design and add CAMEL's IP<br/><img src="figs/4.png" alt="drawing" width="800"/>

5. Now you can use CAMEL's IP<br/><img src="figs/5.png" alt="drawing" width="800"/>
